# 🏠 House Price Prediction

Python • Pandas • NumPy • Scikit-learn • XGBoost • Streamlit • Matplotlib • Seaborn

## 🔍 Key Steps
- **EDA** — Correlation heatmaps, distribution plots, feature analysis
- **Data Cleaning** — Handled missing values across 80+ features
- **Feature Engineering** — Created TotalSF, HouseAge, RemodAge
- **Modeling** — Compared Linear Regression vs XGBoost
- **Deployment** — Live Streamlit web app
